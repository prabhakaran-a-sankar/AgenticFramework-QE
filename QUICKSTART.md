# Quality Engineering Agentic Framework v2.0.0

Fresh clone from: https://github.com/AbhiDixit-Accen/AgenticFramework-QE/tree/v2.0.0

## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Start Backend
```bash
.\start_backend.bat
```

### 3. Start Frontend (in new terminal)
```bash
.\start_frontend.bat
```

## Features

- Knowledge Hub
- Test Case Generation
- Test Script Generation
- Test Data Generation

## Access

- Frontend: http://localhost:8501
- Backend API: http://localhost:8080
